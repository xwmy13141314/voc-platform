LLM 提供商配置
Reddit Cookie 认证（备选）
备选方案 - Cookie 认证：如果无法创建 OAuth 应用，可从浏览器提取 Reddit 登录 cookies。
使用步骤：
1. 在浏览器中登录 Reddit (reddit.com)
2. 完全关闭 Chrome/Edge 浏览器（运行时会锁定 cookie 文件）
3. 点击下方「提取 Cookies」按钮，系统会提取并缓存 cookies
4. 提取成功后可重新打开浏览器，后续抓取使用缓存的 cookies

如果提取失败，可切换为手动模式：从浏览器 DevTools → Application → Cookies → reddit.com 复制 cookies。
Reddit OAuth 配置（推荐 - PRAW 官方 API）
推荐方案：使用 PRAW 官方 API（最可靠）
Reddit 已封锁所有匿名访问（JSON/RSS 均返回 403），PRAW 是官方推荐的 Python API 封装库，自动处理 OAuth 认证、速率限制和分页。
配置步骤：
1. 打开 reddit.com/prefs/apps
2. 页面底部找 create another app... → 选择 script 类型
3. 名称填 voc-platform，redirect URI 填 http://localhost
4. 创建后，应用名下方短字符串是 Client ID，secret 旁是 Client Secret
5. 填入下方 Client ID 和 Client Secret 并保存（用户名密码可留空，使用只读模式）
6. 点击「诊断」按钮验证配置是否正确
Instagram 账号配置
Instagram 需要登录才能抓取评论。配置账号后，系统会自动登录并保存 session 供后续复用。
建议使用小号，避免主号被限制。未配置时以匿名模式运行（功能受限）。
Facebook Cookies 配置
Facebook 需要登录 cookies 才能抓取帖子和评论。获取方法：
1. 用浏览器登录 Facebook → 2. 安装 EditThisCookie 扩展 → 3. 访问 facebook.com → 4. 点击扩展导出 cookies（JSON 格式）→ 5. 将 JSON 粘贴到下方
评论质量过滤
入库前过滤低质量评论（太短 / 纯表情 / 纯链接 / 低赞），从源头降低信噪比与 LLM 分析成本。
被过滤的评论不会删除，仅标记为已过滤、不进入分析队列；调整阈值后点击「重算」可将新规则应用到全部历史评论，无需重新抓取。
中文按字数、英文按词数，低于此值过滤
原文含 URL 且（残留文本少于该词数 或 命中促销话术如 buy here / use code / % off / official store）→ 过滤（拦导购带货评论，真实用户长评论不受影响）
0 = 不按点赞过滤
深度 ≥ 此值仅打标记并扣质量分，不过滤
质量分扣减幅度（0-1）
聚类依赖目录（桌面版）
桌面精简版 EXE 未内置聚类科学计算栈（torch / umap / hdbscan 约 1GB）。在此指定一个已安装好聚类依赖的 site-packages 目录（如源码模式 venv 的 .venv\Lib\site-packages），桌面版即可直接重跑聚类，无需切换源码模式。
要求：该目录的 Python 版本与桌面版一致（Python 3.12 / cp312），点「测试」会自动校验。
报告导出配置
设置导出文件的保存目录。导出 HTML 报告时会自动保存到该目录；导出 PDF 时通过系统打印对话框选择保存位置。
